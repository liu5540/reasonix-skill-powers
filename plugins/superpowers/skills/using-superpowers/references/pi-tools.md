# Pi 工具映射

技能以动作形式表达（“调度子代理”、“创建待办事项”、“读取文件”）。在 Pi 上，这些动作对应到以下工具。

| 技能请求的动作 | Pi 等效工具 |
| --- | --- |
| 调度子代理（`Subagent (general-purpose):` 模板） | 使用已安装的子代理工具，例如 `pi-subagents` 提供的 `subagent`（如果可用） |
| 任务跟踪（“create a todo”、“mark complete”） | 使用已安装的 todo/task 工具；如果没有，则在计划或 `TODO.md` 中跟踪任务 |

## 子代理

Pi 核心未内置标准子代理工具。`pi-subagents` 包是一个强大的可选配套组件，提供 `subagent` 工具，支持单代理、链式、并行、异步、分叉上下文以及恢复/状态工作流。如果没有可用的子代理工具，不要伪造 `Task` 调用；应在当前会话中顺序执行，或说明可选的子代理能力未安装。

## 任务列表

Pi 核心未内置标准任务列表工具。如果安装了 todo/task 扩展，使用其文档中说明的工具。否则，使用 Superpowers 计划文件、Markdown 中的检查清单，或仓库本地的 `TODO.md` 来跟踪任务。较早的 Superpowers 文档可能提到 `TodoWrite`；将其视为上述任务跟踪动作。
