# 代码质量审查子代理提示模板

在分派代码质量审查子代理时使用此模板。

**目的：** 验证实现是否构建良好（干净、已测试、可维护）

**仅在规格合规审查通过后分派。**

```
task 子代理：
  使用 requesting-code-review/code-reviewer.md 中的模板

  DESCRIPTION: [任务摘要，来自实现者的报告]
  PLAN_OR_REQUIREMENTS: 来自 [计划文件] 的任务 N
  BASE_SHA: [任务前的提交]
  HEAD_SHA: [当前提交]
```

**除标准代码质量关注点外，审查者还应检查：**
- 每个文件是否有清晰的职责和良好定义的接口？
- 单元分解是否使得它们可被独立理解和测试？
- 实现是否遵循计划中的文件结构？
- 此实现创建的新文件是否已很大，或显著增大了已有文件？（不要标记已存在的文件大小——聚焦于此变更贡献了什么。）

**代码审查者返回：** 优点、问题（严重/重要/次要）、评估
